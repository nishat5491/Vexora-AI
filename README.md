# Vexora AI — Static GitHub Website

Pure HTML/CSS/JavaScript. No Node.js, npm, React, or build step.

## GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the repository root.
2. GitHub → Settings → Pages.
3. Deploy from the `main` branch and `/ (root)`.

The site includes the premium Vexora UI, futuristic logo, responsive layout, interactive demo modal, animated prompt rotation, cursor glow, and cursor particle trail.
